# Project Notes

This repository is intended to accompany the Week 1 internship report.

The code is deliberately kept understandable and beginner-friendly. The dataset is simulated,
so results should be treated as demonstrations of the analytical workflow rather than claims
about a real logistics company.

Recommended next steps:

2. Add charts for KPI trends.
3. Add a clustering model for delivery-area segmentation.
4. Add a route optimization module after route/order constraints are defined.
